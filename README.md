

# EcoGuard: Climate Data Poisoning Detector

EcoGuard is a real-time stream-processing and validation security layer that intercepts, validates, and filters incoming IoT sensor telemetry on the fly to protect decentralized environmental networks from data poisoning, spoofing, and tampering at ingestion.

## 🚀 Live Demo
* **Live App:** [https://ramon-data.netlify.app](https://ramon-data.netlify.app)

## ✨ Key Features
* **Real-Time Ingestion:** Continuous stream processing of environmental sensor feeds.
* **Statistical Anomaly Detection:** Instantly flags corrupted data points, sudden spoofed spikes, and injected anomalies.
* **Zero-Trust Filtering:** Sanitizes data streams before they reach downstream climate analytics and storage pipelines.
* **Responsive Dashboard:** Built for active monitoring and instant visualization of active threat states.

## 🛠️ Built With
* JavaScript / Frontend Stream Processing
* Netlify (Deployment & Hosting)
* IoT Security & Telemetry Architecture
